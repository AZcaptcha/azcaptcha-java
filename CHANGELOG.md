# Changelog

## 1.0.0 — 2026-11-18

- Initial release against `spec-v1.0.0`.
- Sync client, `CompletableFuture` facade, injectable transport and sleeper.
- Legacy and modern APIs; typed exception with category enum.
- Helpers: image, reCAPTCHA v2/v3, hCaptcha, Turnstile, FunCaptcha, GeeTest.
- Proxy normalisation; polling with `NO_SLOT` backoff.
